# 三国志その後（諸葛亮死後〜司馬炎崩御）マンガ制作プロジェクト

本リポジトリは、三国志の諸葛亮没（西暦234年）から司馬炎崩御・天下統一（西暦280〜290年）までの歴史を描くマンガ作品の企画・プロット・ネーム原作・設定資料を管理するリポジトリです。

## プロジェクト概要
- **対象期間**: 西暦234年（五丈原の戦い・諸葛亮没）〜 西暦280年（呉滅亡・三国統一）〜 西暦290年（司馬炎崩御）
- **主要テーマ**:
  - 「諸葛亮死後、英雄たちの遺志を継いだ者たちと、乱世の収束」
  - 魏・蜀・呉の各国内における権力抗争と世代交代
  - 司馬一族の台頭と西晋による天下統一の軌跡

## 想定構成・ボリューム案
全3部構成（全10巻前後・約1,800〜2,000ページ想定）：
1. **第1部：巨星落つ・後継者たちの苦闘（西暦234〜249年）**（約500ページ）
   - 諸葛亮没後の蜀（蒋琬・費禕体制と姜維）
   - 魏の内紛（司馬懿 vs 曹爽、高平陵の変）
   - 呉の後継者争い（二宮の変、陸遜の憤死）
2. **第2部：蜀漢の落日と司馬氏の専権（西暦250〜264年）**（約700ページ）
   - 姜維の北伐と黄皓の専横
   - 諸葛誕の乱・毋丘倹の乱
   - 魏の蜀侵攻（鄧艾・鍾会）と蜀漢滅亡
   - 鍾会・姜維の反乱と死
3. **第3部：三国の終焉と新王朝の黄昏（西暦265〜290年）**（約600〜800ページ）
   - 司馬炎の即位（西晋建国）
   - 呉の暴君・孫晧と陸抗・羊祜の国境の絆
   - 西晋の呉征伐（王濬の船団、杜預の活躍）と三国統一
   - 統一後の司馬炎の治世と崩御、次代への影
