PAGE 1-2 【巻頭カラー見開き】 情景描写

建興十二年、八月――。
吹き抜ける五丈原の冷たい秋風に、無数の漢軍の旗が激しく軋む。
対峙する魏軍の大軍勢を前に、男の命の炎は、いま静かに消えようとしていた。

【作画指示】 見開き全体に広がる荒涼とした五丈原の台地。蜀と魏の陣営が渭水を挟んで対峙。空は鉛色に曇り、乾いた草が舞う。画面右端に、小さく本陣の天幕。

諸葛孔明、陣没。享年五十四。
それは漢王朝の灯火が、永遠に失われた瞬間であった。

【事件の衝撃的結末：250年・孫権の大粛清】

争いに疲れ果てた孫権は、「孫和を廃嫡して庶人に落とし、孫覇には自害を命じる」という両成敗の狂気的決断を下す。
結果、わずか8歳の末子・孫亮が皇太子となり、名臣を失った呉は諸葛恪・孫峻・孫綝らの専横と暗殺の泥沼へ沈んでいく。

Character Profiles

主要人物名鑑

三国志の黄昏を駆け抜けた群雄・知将たち

姜

姜維（伯約）蜀・大将軍

「孔明の遺志を背負い続けた悲劇の後継者」

孔明の死後、蜀漢の軍事権を握り北伐を継続。しかし連年の出兵は国力を疲弊させ国内の孤立を招く。蜀滅亡後も鍾会を抱き込んで起死回生の反乱を試みる。

陸

陸遜（伯言）呉・丞相大都督

「主君の老害化に散った呉の至宝」

夷陵の英雄にして呉の屋台骨。二宮事件で正論の諫言を続けたため孫権から度重なる詰問と問責を受け、心労と悔しさのあまり武昌の地で憤死する。

司

司馬懿（仲達）魏・太傅

「老獪にして冷酷、晋王朝の礎を築いた巨魁」

孔明の侵攻を防ぎ切った後、曹爽一派を「高平陵の変」で電撃的に一網打尽。魏の皇帝権力を実質的に奪い、司馬氏による専権体制を築き上げた。

炎

司馬炎（安世）西晋・初代皇帝（武帝）

「三国を統一し、そして乱の種を蒔いた覇王」

魏を禅譲により廃して西晋を創始。西暦280年、呉を平定してついに天下統一を果たす。しかし晩年は後宮の美女1万人に溺れ、八王の乱の引き金を引く。
