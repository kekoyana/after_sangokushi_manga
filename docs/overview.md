# プロジェクト詳細・企画概要

## 1. プロジェクト概要
- **対象期間**: 西暦234年（五丈原の戦い・諸葛亮没）〜 西暦280年（呉滅亡・三国統一）〜 西暦290年（司馬炎崩御）
- **主要テーマ**:
  - 「諸葛亮死後、英雄たちの遺志を継いだ者たちと、乱世の収束」
  - 魏・蜀・呉の各国内における権力抗争と世代交代
  - 司馬一族の台頭と西晋による天下統一の軌跡

---

## 2. 制作方針
- **第1話の起点**: 諸葛亮が五丈原で没する瞬間からスタート。英雄の退場と残された者たちの対立（姜維・楊儀・魏延）を克明に描く。
- **重点描写**: 呉の「二宮事件（南魯の党争）」をはじめとする宮廷政治劇・権力闘争を徹底的に深く掘り下げる。

---

## 3. 全体構成案（全3部構成・約1,800〜2,000ページ想定）

### 第1部：巨星落つ・後継者たちの苦闘（西暦234〜249年 / 約500ページ）
- 第1話：諸葛亮没（五丈原の秋風）と蜀軍撤退
- 魏延の反乱と死、蒋琬・費禕体制の確立
- 魏の専権争い（司馬懿 vs 曹爽、高平陵の変）
- **呉・二宮事件（南魯の党争）**: 孫権の老害化、全公主の暗躍、陸遜の憤死、血の粛清

### 第2部：蜀漢の落日と司馬氏の専権（西暦250〜264年 / 約700ページ）
- 姜維の北伐断行と蜀漢国内の疲弊、黄皓の専横
- 魏の内乱（毋丘倹・文欽の乱、諸葛誕の乱）
- 魏の蜀侵攻（鄧艾の山越え進軍、鍾会軍）と蜀漢降伏
- 姜維・鍾会の反乱と最期

### 第3部：三国の終焉と新王朝の黄昏（西暦265〜290年 / 約600〜800ページ）
- 司馬炎の即位（西晋建国・曹奐禅譲）
- 呉の暴君・孫晧の狂気と、名将・陸抗と羊祜の知己・国境の絆
- 西晋の呉征伐（王濬の楼船水軍、杜預破竹の勢い）と三国統一
- 統一後の司馬炎の奢侈、白痴の恵帝、八王の乱の萌芽、司馬炎崩御
